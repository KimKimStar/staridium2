# 둥글이 그린스크린(Chroma-Key) 에셋 안내

이 디렉토리에 **`sample_greenscreen.mp4`** 파일을 배치해 두시면, 백엔드 FFmpeg 파이프라인에서 자동으로 초록색(#00FF00) 배경을 투명하게 제거하고 유저의 장소 사진(Ken Burns Zoom-in 동적 배경) 위에 오버레이하여 최종 9:16 숏폼을 합성합니다.

### 권장 규격
- **파일명**: `sample_greenscreen.mp4`
- **배경색**: 선명한 녹색 (`#00FF00`, RGB: 0, 255, 0)
- **해상도**: 세로 9:16 (예: 720x1280 또는 1080x1920)
- **길이**: 5초 ~ 10초 내외의 아기 캐릭터 '둥글이'의 인사/리액션 동작
- **코덱**: H.264 (mp4)

> 💡 파일이 아직 없는 경우에도 스튜디오 대시보드는 데모 비디오 스트림을 통해 끊김 없이 시연 UI를 확인하실 수 있습니다.
